# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x (main) | Yes |

## Reporting a vulnerability

**Do not** open public GitHub issues for security vulnerabilities.

Instead, report concerns privately to Tiger Studio / Wab maintainers with:

1. A description of the issue
2. Steps to reproduce (if applicable)
3. Potential impact
4. Any suggested remediation

Maintainers will acknowledge receipt and provide a timeline for review.

## Scope

This policy covers:

- This repository's source code and project files
- Build or export configuration checked into the repository
- Documentation that could expose unsafe operational guidance

This policy does not cover third-party services (GitHub, Godot Engine upstream, hosting providers) except where this project's configuration materially affects their use.

## Safe disclosure

Please allow reasonable time for investigation and patching before public disclosure. Coordinated disclosure helps protect users and collaborators.

## Out of scope examples

- Social engineering against individual contributors
- Denial-of-service attacks against public infrastructure
- Issues requiring physical access to a developer machine
- Vulnerabilities in Godot Engine itself (report those to the Godot project)
